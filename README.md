# Altug Brandworks — Sürümler

**Digital • Creative • Branding**

Bu depo yalnızca Altug Brandworks Windows uygulamasının kurulum dosyalarını ve
otomatik güncelleme bilgisini barındırır.

## İndir (Windows)

**[AltugBrandworks-Setup-1.1.0.exe](https://media.githubusercontent.com/media/AltugAI/altug-brandworks-releases/main/windows/AltugBrandworks-Setup-1.1.0.exe)**

Kurulumdan sonra uygulama yeni sürümleri kendisi bulur ve günceller.

> Windows "Bilgisayarınız korundu" uyarısı gösterirse: **Ek bilgi → Yine de çalıştır**.

## Sürüm notları

### 1.1.0
- Müşteri kayıtları: iletişim bilgileri, tarz ve notlar
- Her müşteriye ait dosya klasörü (logo, kartvizit, QR, sosyal medya, diğer)
- Sürükle-bırak ile dosya ekleme ve görsel önizleme

### 1.0.0
- Özel açılış ekranı, modern arayüz, ayarlar ve otomatik güncelleme altyapısı
