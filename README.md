# Altug Brandworks — Sürümler

**Digital • Creative • Branding**

Bu depo yalnızca Altug Brandworks Windows uygulamasının kurulum dosyalarını barındırır.

## İndir (Windows)

En son sürüm: **[Releases sayfası](https://github.com/AltugAI/altug-brandworks-releases/releases/latest)**
→ `AltugBrandworks-Setup-<sürüm>.exe` dosyasını indirin.

Kurulumdan sonra uygulama yeni sürümleri kendisi bulur ve günceller.

> Windows "Bilgisayarınız korundu" uyarısı gösterirse: **Ek bilgi → Yine de çalıştır**.
